1. Julretsu について

Julretsu は Windows、macOS、Linux 用のデスクトップ スプレッドシートです。使い慣れたスプレッドシートと同じように動きます。セルのグリッド、入力するたびに再計算される数式、書式、並べ替え、グラフ、印刷がそろっています。ブックはお使いのコンピューターの中だけに保存されます。

Julretsu ならではの特長はセーフティ ネットです。金額の打ち間違い、行が抜けた合計、1 行ずれた貼り付けといったスプレッドシートのミスは、毎年多くの企業に実際の損失をもたらしています。Julretsu は編集した時点でそれを見つけ、大きな変更は確定する前に見せ、すべての変更をブックの中に記録します。

Julretsu でできること

  • 最大 1,000,000 行、16,384 列のシートで予算、価格表、スケジュール、レポートを作成できます。
  • SUM、AVERAGE、IF などの数式を使い、ワークシート同士を参照できます。
  • フォント、色、罫線、通貨、パーセンテージ、日付でセルの書式を設定できます。
  • CSV ファイルや Microsoft Excel の .xlsx ブックを開いて保存できます。
  • 選択範囲を棒グラフや折れ線グラフにして、レポートとしてエクスポートしたり、印刷したり、PDF として保存できます。
  • 英語、韓国語、日本語で使えます。セルにもそのまま入力できます。
  • 短い Lua マクロで繰り返しの編集を自動化できます。
  • 必要なら AI モデルに編集を提案させ、適用する前に自分で確認できます。
ヒント. Julretsu はサンプルのプロジェクト予算とともに起動します。このマニュアルの画面はすべてそのサンプルを使っているので、そのまま試せます。

2. Julretsu のインストール

Julretsu の Web サイトからお使いのコンピューター用のインストーラーをダウンロードしてください。Julretsu 1.2.0 には次のパッケージがあります。

コンピューターファイル動作条件
WindowsJulretsu-1.2.0-Windows-Setup.exeWindows 10 または 11 (64 ビット)、OpenGL 3.3 に対応したグラフィックス
MacJulretsu-1.2.0-macOS.dmgmacOS 13.3 Ventura 以降、Apple シリコンまたは Intel
Linux (Ubuntu、Debian、Mint)Julretsu-1.2.0-linux-amd64.deb64 ビットの Intel または AMD、X11 か XWayland のデスクトップ
Linux (すべてのディストリビューション)Julretsu-1.2.0-linux-x86_64.tar.gz上と同じ。インストール不要です

Windows

  1. Julretsu-1.2.0-Windows-Setup.exe をダブルクリックします。
  2. ライセンスを読み、Julretsu ソフトウェア ライセンスに同意します にチェックを入れて 次へ をクリックします。
  3. Julretsu をインストールする場所を選びます。既定のフォルダーはご自分のユーザー フォルダー内なので、管理者権限は必要ありません。
  4. オプションを選びます。スタート メニューの項目、デスクトップのショートカット、.julretsu のブックをダブルクリックしたときに Julretsu で開くかどうかを指定できます。
  5. インストール をクリックします。完了したら 今すぐ Julretsu を開始 にチェックを入れたまま 完了 をクリックします。
Windows で「WindowsによってPCが保護されました」と表示されたら. このメッセージは、Windows がまだあまり見ていない新しいプログラムで表示されます。詳細情報 をクリックし、発行元とファイル名が想定どおりか確認してから 実行 をクリックしてください。

Mac

  1. Julretsu-1.2.0-macOS.dmg をダブルクリックして開きます。
  2. 同じウィンドウに表示される アプリケーション フォルダーへ Julretsu をドラッグします。
  3. アプリケーション フォルダーを開いて Julretsu を起動します。
macOS が悪質なソフトウェアかどうか確認できないと表示したら. 初回だけ、アプリケーション フォルダーの Julretsu を Control キーを押しながら (または右クリックで) クリックして 開く を選び、もう一度 開く をクリックしてください。システム設定、プライバシーとセキュリティ で このまま開く をクリックしてもかまいません。この操作は一度だけで済みます。

Linux

Ubuntu、Debian、Linux Mint など: .deb ファイルをダブルクリックしてソフトウェア センターからインストールするか、ダウンロードしたフォルダーで次のコマンドを実行します。

sudo apt install ./Julretsu-1.2.0-linux-amd64.deb

インストールすると、アプリケーション メニューに Julretsu が表示され、.julretsu ファイルが Julretsu で開きます。

その他のディストリビューション: .tar.gz ファイルを好きな場所に展開し、展開したフォルダー内の bin/julretsu を実行します。

メモ. Linux では、Julretsu はデスクトップ側のファイル ダイアログを使います。zenity または kdialog が必要というメッセージが出たら、どちらかをインストールしてください (例: sudo apt install zenity)。

4. データの入力と編集

セルの選択

  • セルをクリックして選択します。矢印キー、Tab、Page Up、Page Down で移動します。
  • 別のセルを Shift+クリックすると、その間の長方形の範囲が選択されます。
  • 行番号をクリックすると行全体が選択されます。Ctrl+クリックで行を追加または解除し、Shift+クリックで連続した行を選択します。
  • Ctrl+Home で A1 に移動します。編集メニューの 使用範囲を選択 は、データのある範囲をすべて選択します。

値の入力と変更

  1. セルをダブルクリックするか F2 を押します。数式バーをクリックしてもかまいません。
  2. 数値、文字列、TRUE、FALSE、または = で始まる数式を入力します。
  3. Enter で変更が確定し、Esc で取り消します。
ヒント. = で始まる文字列や数値に見える文字列をそのまま保存するには、先頭にアポストロフィを付けます。たとえば '=hello や '00123 は入力したとおりに保持されます。

長い文字列は自分のセル内だけに表示され、末尾が「...」になります。セルにマウスを合わせるか数式バーを見ると全体を確認できます。セルより広い数値は読み間違えないように ### と表示されます。ズームするか数式バーで確認してください。

元に戻すとやり直し

Ctrl+Z で元に戻し、Ctrl+Y でやり直します。クイック アクセスのボタンでも操作できます。貼り付け、並べ替え、マクロは 1 回の操作で元に戻ります。

コピー、切り取り、貼り付け

  • Ctrl+C でコピー、Ctrl+X で切り取り、Ctrl+V で貼り付けます。一度にコピーできるのは最大 10,000 セルです。
  • Ctrl+Shift+V は、数式や書式なしで値だけを貼り付けます。
  • Julretsu 内でコピーすると数式と書式も保たれます。相対参照は貼り付け先に合わせて変わり、$ を付けた参照は固定されます。
  • Web ページの行やほかのスプレッドシートなど、別のプログラムからコピーした文字列も貼り付けられます。

連続データの入力

選択範囲の角にある小さな四角を下または右にドラッグします。数式は参照が調整された状態でコピーされます。5 と 10 のように数値 2 つから始めると、Julretsu が 15、20、25 と連続データを続けます。ホーム、編集、フィル から下方向や右方向にコピーすることもできます。

検索

Ctrl+F を押すと、現在のシートの値と数式を検索します。次を検索 をクリックすると、一致するセルを順に確認できます。

5. 数式

数式は = で始まり、参照しているセルが変わると自動的に再計算されます。たとえばサンプルの予算では、E4 セルに =C4*D4、つまり数量 × 単価が入っています。

基本の要素

使えるもの例
数値、引用符で囲んだ文字列、TRUE と FALSE=42、="Paid"、=TRUE
セル参照と範囲=B2、=SUM(B2:B9)、=SUM(A1:C3)
四則演算+ - * / とかっこ (例: =(B2+B3)*1.2)
比較= <> < <= > >= (例: =B2>100)

関数

関数はたらき例
SUM数値を合計します。文字列と空のセルは無視されます。=SUM(E4:E9)
AVERAGE範囲内の数値の平均です。=AVERAGE(D4:D9)
IF2 つの結果から 1 つを選びます。条件、真のときの結果、偽のときの結果の 3 つが必ず必要です。=IF(E4>1000,"Review","OK")
SHEET別のワークシートのセルを読みます。=SHEET("Budget","E11")
LUA短い Lua の計算を実行します。=LUA("return cell('E11') * 1.05")

列を合計する一番早い方法は、列を選んで ホーム、編集、オート SUM、合計 を選ぶことです。Julretsu が選択範囲のすぐ下に SUM の数式を入れます。

数式にエラーが表示されたら

表示意味
#DIV/0!0 で割ったか、数値のない範囲の平均を求めました。
#VALUE!数値が必要な場所に文字列が使われています。
#REF!参照がシートの外を指しています。
#NAME?関数名が不明です。
#CYCLE!数式が直接、またはほかのセルを通じて自分自身を参照しています。
#NUM!結果が大きすぎて表せません。
#PARSE!数式を読み取れませんでした。かっこと引用符を確認してください。
ヒント. 表示、数式の表示 をオンにすると、結果ではなくすべての数式がグリッドに表示されます。

ホーム リボンには、ふだん使う書式のツールがそろっています。選択したセルに適用され、行番号をクリックして行全体を選んだ場合はその行に適用されます。

配置左揃え、中央揃え、右揃え、または自動 (数値は右、文字列は左)。
数値標準、数値、通貨、パーセンテージ、日付、桁区切りの表示形式と、小数点以下の桁数の増減。

セルの書式設定ダイアログ

細かく指定するには 書式、選択したセルの書式設定 (または セル、書式、セルの書式設定) を選びます。フォントの種類 (ゴシック体、明朝体、等幅)、サイズ、太字、罫線、配置、表示形式、小数点以下の桁数、文字色と塗りつぶしの色を設定できます。

行全体の書式設定

書式 タブには行全体に使える手早いツールがあります。行を太字に、緑の塗りつぶし、小数点以下の増減、リセットです。見出し行や合計行に便利です。

ワンクリックで表を書式設定

見出し行を含めて表を選び、ホーム、スタイル、テーブル スタイル から色を選びます。Julretsu が見出しを太字にして色を付け、罫線を引き、1 行おきに色を敷きます。

7. 行、列、並べ替え、フィルター

挿入と削除

セルを選んでから ホーム、セル、挿入 または 削除 を使います (データ メニューにもあります)。行は選択したセルの上に、列は左に挿入されます。ほかの場所の数式は、正しいセルを指したままになるように更新されます。

メモ. Julretsu は、ほかの数式が参照している行や列を削除しません。黙って数式が壊れてしまうからです。また SHEET と LUA の参照は自動で調整できないため、挿入や削除の前に取り除くよう案内します。

並べ替え

  1. 並べ替える行を選びます。その行に属する列をすべて含め、見出し行は含めません。
  2. 並べ替えの基準にする列のセルをクリックして、アクティブ セルにします。
  3. ホーム、編集、並べ替えとフィルター を選び、昇順 または 降順 を選びます。
セーフティ ネット. 選択範囲の隣の列に同じ行のデータがあると、Julretsu がすぐに知らせます。表の一部だけを並べ替えると行がずれてしまうからです。変更を元に戻す を選び、表全体を選択し直してください。

フィルター

フィルターをかけたい列のセルをクリックし、データ、アクティブな列でフィルター を選んで探す文字を入力します。その文字を含む行だけが表示され (大文字と小文字は区別されます)、1 行目は見出しとして常に表示されます。すべて表示に戻すには データ、フィルターを解除 を選びます。フィルターでデータが削除されることはありません。非表示の行を守るため、並べ替え、貼り付け、削除の前にはフィルターを解除してください。

見出しの固定

表示 メニューで 先頭行の固定、先頭列の固定、またはその両方を選ぶと、スクロールしても見出しが表示されたままになります。

構造化テーブル

構造化テーブルはひとまとまりのデータを束ねて、表が正しく伸びるようにします。見出し行と 1 行以上のデータ行を選び、データ、構造化テーブル を選んで名前を入力し、選択範囲からテーブルを作成 をクリックします。集計行を追加 にチェックを入れると、数値の列ごとに Julretsu が合計を作成して管理します。

  • 新しい行は 1 つ上の行の数式、書式、入力規則を引き継ぐので、単価や合計の列は計算され続けます。
  • 集計行のあるテーブルは テーブルに行を追加 で伸ばします。新しい行が集計の上に挿入され、集計の範囲も広がります。
  • 集計行のないテーブルは、すぐ下の最初の空行に入力するだけでも自動で広がります。
  • テーブル定義を削除 は自動的な動きだけを止め、セル、書式、規則はそのまま残します。元に戻す操作で定義を復元できます。
メモ. 見出しは空白にせず、それぞれ異なる必要があります。テーブル同士は重ねられず、1 つのテーブルは最大 100,000 セルです。行や列を挿入、削除する前にテーブル定義を削除し、伸ばすときはテーブルに行を追加を使ってください。

8. 複数のワークシートを使う

1 つのブックにワークシートを最大 64 枚まで入れられます。グリッド左下のシート ボタンでシートを切り替え、ブック、シートの管理 で追加、複製、名前の変更、並べ替え、削除ができます。

別のシートの値を使うには、SHEET にシート名とセル番地を引用符付きで指定します (例: =SHEET("Q1 Sales","B12"))。シート名を変更したら、数式の中の名前も更新してください。

注意. ワークシートを削除すると、その内容はすべて失われ、元に戻せません。Julretsu は先に確認を求めます。

9. 保存、開く、回復

Julretsu のブック

Ctrl+S、クイック アクセスの保存ボタン、または ファイル、保存 で保存します。初回はフォルダーと名前を指定します。別のコピーとして保存するには ファイル、名前を付けて保存 (Ctrl+Shift+S) を使います。ブックは Ctrl+O で開くか、.julretsu ファイルをダブルクリックして開きます。

.julretsu ファイルには、値、数式、書式、すべてのワークシート、Lua スクリプト、変更履歴がすべて保存されます。未保存の変更があるブックを閉じたり置き換えたりするときは、Julretsu が必ず確認します。

自動回復

未保存の作業が 1 分続くと、Julretsu は静かに回復用のコピーを作り、1 分ごとに更新します。Julretsu やコンピューターが不意に終了した場合、次回起動時にそのコピーを復元するか尋ねます。復元 を選び、名前を付けて保存 でブックを保存してください。通常どおり保存または終了すると、回復用のコピーは削除されます。ブック メニューからオフにしたり、手動で開いたりもできます。

復元ポイント

復元ポイントは、あとで戻れるブック全体のスナップショットです。編集、復元ポイント、または 校閲 タブの 復元ポイント ボタンを使います。先にブックを保存し、名前を入力して 復元ポイントを作成 をクリックします。

  1. 一覧で復元ポイントを選ぶと、それ以降の変更を確認できます。違いのあるセルの数と、ワークシート、書式、規則の変更が表示されます。
  2. 選択したバージョンを復元 をクリックします。Julretsu はまず現在の作業の安全コピーを 復元前 という名前で保存します。
  3. 結果を確認してから保存して確定します。思っていた内容と違う場合は、安全コピーを復元してください。

保存するたびに Julretsu は 保存前 の復元ポイントも作るので、うまくいかなかった編集だけが残ることはありません。

メモ. 復元ポイントはブックのファイルの隣にある履歴フォルダーに保存されるので、ファイルを移動するときはフォルダーも一緒に移動してください。Julretsu は自動の復元ポイントを最新 20 件、名前付きのものを最大 100 件保持します。

10. CSV と Excel のファイル

CSV ファイル

ファイル、CSV のインポート と ファイル、CSV のエクスポート を使います。Julretsu は UTF-8 の CSV ファイルを読み書きし、カンマ、引用符、複数行を含む値にも対応します。インポート時は数値と TRUE、FALSE が認識され、それ以外は文字列になります。CSV ファイル内の数式が実行されることはありません。

エクスポートした CSV ファイルには計算結果が入ります。=、+、-、@ で始まる文字列は先頭にアポストロフィを付けて保護するため、ほかのスプレッドシート ソフトが数式として実行することはありません。

Excel のブック

ファイル、Excel のインポート は .xlsx ファイルのすべてのワークシートを、セルごとの書式と対応する入力規則とともに読み込みます。Excel が最後に計算した結果を取り込むには 保存された値 を、四則演算、比較、SUM、AVERAGE、IF を数式のまま残すには 対応する数式 を選びます。別のシートへの参照は SHEET の数式として入ります。読み込む前に、シートごとに何が取り込まれ、何が取り込まれないかを Julretsu が正確に表示します。

ファイル、Excel のエクスポート は、ブック全体を .xlsx ファイルとして保存します。すべてのワークシート、対応する数式、セルの書式、そして Excel が扱えるドロップダウン、数値、日付の規則が含まれます。Excel で表せない数式は計算結果の値として書き出され、その件数をメッセージで知らせます。

メモ. Excel 側の制限があるため、シート名は重複せず 31 文字以内、ドロップダウンはカンマや引用符を含まず 255 文字以内、入力規則の範囲は重ならないようにする必要があります。Julretsu は規則を黙って捨てず、どれを直せばよいかを知らせます。
メモ. セルの結合、グラフ、列幅、コメントといった Excel の機能はインポートもエクスポートもされず、1904 年日付システムのブックには対応していません。すべてを保持するには .julretsu のコピーを残してください。

11. セーフティ ネット

Julretsu は、高くつくスプレッドシートのミスの裏にある日常的な間違いに目を配ります。作業を止めることはありません。どこがおかしく見えるかを説明し、判断はあなたに任せます。

危険な変更は確定する前に確認

大きな貼り付け、フィル、クリア、マクロのあと、データの入っていた行や列を削除したあと、隣の列を残したまま並べ替えたあと、または数式が上書きされたとき、Julretsu は この変更を確認 を表示します。変更はすでにシートに反映されており、ダイアログには影響を受けたセルが変更前と変更後の値とともに並びます。

  • 変更を保持 (Enter) でそのまま残します。
  • 変更を元に戻す (Esc) ですべてが元どおりになります。

校閲 タブでは、何個のセルが変わったら確認するかを決めたり、確認をオフにしたりできます。一部だけの並べ替え、削除されたデータ、置き換えられた数式、桁違いの数値は常に確認します。

入力ミスの即時チェック

同じ列のほかの値よりはるかに大きい、または小さい数値を入力すると (たとえば 450 前後の金額が並ぶ列に 4500000)、ステータス バーがすぐに知らせます。入力ミスなら Ctrl+Z を押してください。

シートチェック

ステータス バーの シートチェック バッジは、シートに問題があるかどうかを常に表示します。バッジをクリックするか 校閲、シートをチェック を選ぶとパネルが開きます。Julretsu は次のものを探します:

  • 同じ数式が続く列の中にある、直接入力された数値や異なる数式
  • 隣の数値を取りこぼしている SUM や AVERAGE の範囲
  • 同じ列のほかの値と桁が大きく違う数値
  • 合計が黙って飛ばしてしまう、文字列として保存された数値
  • 表を分断し、並べ替えやフィルターを止めてしまう空白行

それぞれの問題には 移動、安全な修正がある場合のワンクリック修正、無視 があります。赤い点は、誤った結果になりやすい問題です。修正はすべて元に戻せます。

セルの履歴と変更履歴

セルを右クリックして セルの履歴 を選ぶか、校閲、セルの履歴 を使うと、そのセルのすべての変更を確認できます。いつ、何によって変わったのか、変更前と変更後の値が表示されます。校閲、変更履歴 はシート上のすべての変更を一覧にします。

履歴は .julretsu ファイルの中に保存されるので、ブックと一緒に移動します。Julretsu は直近 1,000 件の変更を保持し、非常に大きな変更は最初の 200 個のセルだけを表示します。ファイルを共有するときに履歴を含めたくない場合は、変更履歴を開いて 履歴を消去 を選んでください。

入力規則と保護

入力規則は、セルに入れてよい値を決めておき、誤った値を入力した時点で拒否します。範囲を選んでから データ、入力規則と保護、または 校閲 タブのボタンを使います。

許可する値受け付ける値
すべての値何でも受け付けます。入力を必須にする設定や保護と組み合わせると便利です。
数値、整数最小値と最大値の間の値 (両端を含む)。
日付YYYY-MM-DD 形式で書いた 2 つの日付の間の日付。
ドロップダウン リスト1 行に 1 つずつ入力した選択肢のいずれか。最大 100 項目まで指定できます。
  • 入力を必須にする は空のセルを拒否し、この範囲で値の重複を禁止 は重複した値を拒否します。
  • 内容と書式を保護 はその範囲の編集を禁止します。保護された数式も再計算は続きます。
  • 無効な値を拒否せず警告を表示 を選ぶと入力は通り、その内容が 検証結果 に表示されます。

規則は入力だけでなくすべての操作に適用されます。規則に反する貼り付け、フィル、並べ替え、マクロ、AI の提案は全体が拒否されるので、途中まで適用されることはありません。すでに問題のあるシートに規則を追加しても、データはそのままで問題の一覧が表示されます。一覧のセル番地をクリックすると、そのセルへ移動します。

注意. 保護は事故を防ぐためのもので、パスワードや権限の仕組みではありません。ブックを持っている人は誰でも規則を削除できます。規則は .julretsu ファイルにのみ保存され、CSV や Excel への書き出しには含まれません。規則のあるブックは Julretsu 1.1.0 以前では開けません。

12. グラフ、レポート、PDF

  1. レポートに入れるセルを選びます。セルを 1 つだけ選んだ場合、Julretsu はシート上の入力済みセルをすべて使います。
  2. レポート、選択範囲のグラフ / 印刷 を選びます。
  3. レポートのタイトルを入力し、グラフにする数値が入っている グラフにする列 を選びます。棒グラフか折れ線グラフ、縦向きか横向き、先頭行を各ページで繰り返すかどうかも選べます。
  4. グラフと表をエクスポート (HTML) をクリックして保存先を選びます。Web ブラウザーで開くとグラフと表を一緒に見られ、ブラウザーの 印刷 で印刷したり PDF として保存したりできます。Windows、Mac、Linux のいずれでも使えます。
  5. Windows では 印刷 / PDF として保存 をクリックして直接印刷することもできます。PDF にするにはプリンターとして Microsoft Print to PDF を選びます。
メモ. レポートには最大 12 列、10,000 セルを含められ、グラフにはグラフ列の数値を最大 1,000 個まで使います。数値が 1 つだけのときは、見やすいように 1 本の棒で表示します。レポートはその時点の写しで、ブックには保存されません。エクスポートした HTML ファイルには必要なものがすべて入っているので、メールで送ったり別のコンピューターで開いたりできます。

サンプル テンプレート

ナビゲーション バーの テンプレート をクリックすると、架空のサンプル データと動く数式が入ったブックを開けます。サンプル ブック の一覧から選び、選択したテンプレートを使う をクリックします。Julretsu は現在のブックを先に保存するか尋ねます。

テンプレート内容
プロジェクト予算カテゴリ別の予定費用と実際の費用、合計と差額。
月別売上12 か月分のオンライン売上と店舗売上を目標と比較します。折れ線グラフ向きです。
家計の支出カテゴリ別の予定額と実際の支出、残額。
在庫計画在庫数、発注点、単価、製品ごとの在庫金額。
週ごとのプロジェクト時間12 週間のデザイン、開発、テストの時間と週ごとの合計。

テンプレートはグラフを手早く試すのに向いています。テンプレートを開いて表を選び、レポート、選択範囲のグラフ / 印刷 を選んでください。

13. Lua マクロ

Lua マクロは繰り返しの編集を自動化します。ナビゲーション バーの Lua ワークスペース、または ホーム、アシスト、Lua スクリプト から開きます。エディターにはスクリプトを書く コード タブと、マクロから呼び出せるものをまとめた クイックリファレンス タブがあります。コードの下にはカーソル位置が表示され、実行結果 に最後の実行内容が出ます。

  • cell('A1') は、マクロが始まる前のセルの値を読みます。
  • set('A1', value) は変更を予約します。
  • マクロを実行 をクリックするか、入力中に Ctrl+Enter を押します。すべての変更がまとめて適用され、マクロを元に戻す で一度に戻せます。

次の例は、予算のすべての数量に 1 を足します。

for row = 4, 9 do set('C' .. row, cell('C' .. row) + 1) end

メモ. マクロは、ファイル、ネットワーク、コンピューターのほかの部分にアクセスできない安全なサンドボックスで、時間とメモリの制限付きで実行されます。失敗したマクロはシートを変更しません。スクリプトはブックとともに保存されますが、ひとりでに実行されることはありません。

14. AI アシスタント (任意)

Julretsu はインターネットなしで完全に動作します。必要なら、ご自分の AI プロバイダーに接続し、「合計の下に 10% の予備費の行を追加して」のようにふだんの言葉で変更を依頼できます。

  1. ナビゲーション バーの AI アシスタント、または ホーム、アシスト、AI に聞く を開きます。
  2. 接続 で Anthropic (Claude) か、OpenAI、Ollama、LM Studio などの OpenAI 互換 サーバーを選び、モデル名を入力して API キーを保存します。
  3. 変更したい内容を説明し、編集を提案 をクリックします。
  4. 提案された編集を変更前と変更後の値とともに確認し、不要なもののチェックを外して 適用 をクリックします。
  • API キーは Windows 資格情報マネージャーがユーザー アカウントごとに保管し、ブックや設定ファイルには保存されません。
  • 送信する前に、何個のセルがどのサーバーへ送られるかをパネルが知らせます。送信される入力済みセルは最大 2,000 個です。
  • Lua の数式を含む編集は、最初はチェックが外れています。[適用] をクリックするまで何も変わらず、Ctrl+Z 一回で提案全体を元に戻せます。
  • 利用料金はプロバイダーからご自身のアカウントに請求されます。
メモ. AI 接続は現在 Windows 版の Julretsu でのみ利用できます。

15. 言語、表示、テーマ

言語を選ぶ

Julretsu は英語、韓国語、日本語に対応しています。初回起動時はコンピューターの言語に従います。変更するには、ナビゲーション バーの 設定 をクリックして 言語 から選ぶか、表示、言語 を使います。選んだ言語はこのデバイスに保存されます。

言語の設定は、メニュー、ボタン、メッセージ、シートチェック、エクスポートしたレポート、新しく作るサンプル ブックに適用されます。ご自分で入力したセルの内容や、すでに保存したブックが翻訳されることはありません。

どの言語設定でも、ふだんお使いの入力方式で韓国語と日本語をどのセルにも入力できます。Julretsu は必要な文字をコンピューターにインストールされたフォントから読み込むので、どのズーム倍率でも文字がくっきり表示されます。

メモ. Linux では、韓国語と日本語の文字を表示できるように Noto Sans CJK などの CJK フォントをインストールしてください (Ubuntu や Debian: sudo apt install fonts-noto-cjk)。Windows と macOS には最初から含まれています。

ダーク モード

右上の ダーク モード をクリックするか、表示、ダーク テーマ を使います。Julretsu は選択を記憶します。

そのほかの表示オプション

  • ズーム: 右下のスライダーをドラッグして 75% から 150% まで調整します。
  • 目盛線 と 数式の表示: 表示メニューと表示タブにあります。
  • 長い文字列を空のセルにはみ出して表示: 昔のスプレッドシートのように、長い文字列が隣の空のセルまで続いて表示されます。
  • リボンを折りたたむ: リボンのタブの横にある矢印をクリックすると表示が広くなります。どれかのタブをクリックすると元に戻ります。

ブックのウィンドウ ボタン

リボンのタブの右にあるボタンはブック自体を操作します。最小化 はウィンドウ下部の小さなバーに縮め、元に戻す は Julretsu の中で移動やサイズ変更ができるウィンドウにし、閉じる はブックを閉じて (先に保存するか尋ねます) 空のブックを開きます。

17. 困ったときは

症状対処
インストール時に Windows が「WindowsによってPCが保護されました」と表示する。詳細情報 をクリックしてから 実行 をクリックします。第 2 章を参照してください。
macOS が Julretsu を悪質なソフトウェアかどうか確認できないと表示する。アプリケーションの Julretsu を Control キーを押しながらクリックして 開く を選ぶか、プライバシーとセキュリティで このまま開く を使います。
Linux で zenity や kdialog に関するメッセージが出る。どちらかをインストールします: sudo apt install zenity。Julretsu が開く / 保存のダイアログに使います。
Julretsu が起動せず、OpenGL やグラフィックスのメッセージが出る。グラフィックス ドライバーを更新してください。Julretsu は Windows と Linux で OpenGL 3.3 を必要とします。
セルに ### と表示される。数値がセルの幅より大きいためです。ズームするか、数式バーで確認してください。
数式にエラー コードが表示される。第 5 章のエラー一覧を確認し、シートチェックのパネルも見てください。
並べ替え、貼り付け、削除ができない。先に有効なフィルターを解除してください (データ、フィルターを解除)。
行の挿入が拒否される。先に SHEET や LUA の参照を取り除いてください。これらは自動で調整できません。
Julretsu を起動すると回復の確認が表示される。前回 Julretsu が不意に終了しました。作業を取り戻すには 復元 を、コピーを破棄するには 現在のブックを保持 を選びます。
.julretsu ファイルをダブルクリックしても Julretsu が開かない。Windows ではインストーラーをもう一度実行し、.julretsu のブックを Julretsu で開く にチェックを入れます。Mac では ファイル、開く から開いてください。

18. Julretsu のアンインストール

  • Windows: 設定、アプリ、インストールされているアプリ で Julretsu を見つけ、アンインストール を選びます。インストール フォルダーの Uninstall Julretsu を使うこともできます。
  • Mac: アプリケーションから Julretsu をゴミ箱にドラッグします。
  • Linux (.deb): sudo apt remove julretsu を実行します。
  • Linux (.tar.gz): 展開したフォルダーを削除します。

アンインストールしてもブックは削除されません。外観の設定はユーザーの設定フォルダーに保存され、必要なら手動で削除できます。
